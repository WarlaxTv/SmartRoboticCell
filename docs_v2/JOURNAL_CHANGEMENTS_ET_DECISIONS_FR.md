# Journal des Changements et Décisions (V2)

Ce document trace toutes les évolutions architecturales majeures et les décisions techniques prises pour la version 2 du projet (Conformité NF EN 9100).

**Légende des Composants :**
- ⚙️ **[OT - OPC UA]** : Serveur de données industrielles (Simulateur d'usine `opcua_server.py`)
- 🌐 **[IT - Web]** : Serveur de supervision et dashboard (FastAPI `web_server.py`)
- 🛡️ **[Global]** : Architecture, Sécurité transverse, Certificats, ou Documentation

| ID | Date | Composant | Description du Changement / Décision | Raison / Justification |
| :---: | :---: | :--- | :--- | :--- |
| **CHG-V2-001** | 2026-04-18 | 🛡️ [Global] | Migration d'un POC monolithique vers une architecture distribuée (Serveur OPC UA simulant l'usine + Serveur Web de Supervision FastAPI). | Respecter le Modèle de Purdue (séparation des réseaux OT et IT). |
| **CHG-V2-002** | 2026-04-18 | 🌐 [IT - Web] | Suppression totale des capacités de contrôle à distance (démarrer, armer, acquitter). L'interface Web est strictement en **Lecture Seule**. | Atténuation des risques d'accidents liés à un mouvement robotique non désiré (Exigence NF EN 9100 Chap. 6.1 et 8.1.1). |
| **CHG-V2-003** | 2026-04-18 | 🛡️ [Global] | Implémentation d'une PKI locale (Public Key Infrastructure) générant des certificats SSL/TLS auto-signés. | Chiffrer les flux de données OPC UA (Basic256Sha256) et les flux Web (HTTPS). |
| **CHG-V2-004** | 2026-04-18 | 🛡️ [Global] | Reprise de la tenue des journaux de traçabilité (Changements, Décisions, Erreurs) avec distinction OT/IT automatisée. | Assurer la traçabilité continue pour les audits de qualité. |
| **CHG-V2-005** | 2026-04-18 | 🛡️ [Global] | Modification du générateur de certificat (`generate_certs.py`) pour inclure l'IP `127.0.0.1` en plus de `localhost` dans les SANs (Subject Alternative Names). Ajout du certificat Web au magasin d'autorités de confiance (Root) de Windows via `certutil`. | Supprimer l'alerte bloquante "Votre connexion n'est pas privée" sur le navigateur local pour une meilleure expérience utilisateur. |
| **CHG-V2-006** | 2026-04-18 | ⚙️ [OT - OPC UA] | Ajout d'une nouvelle variable simulée (`VitesseBras` en %) dans le modèle de données du serveur OPC UA, conditionnée par l'état de la cellule (0% si en défaut). | Enrichir le jumeau numérique avec des métriques industrielles réalistes. |
| **CHG-V2-007** | 2026-04-18 | 🌐 [IT - Web] | Mise à jour du client OPC UA (FastAPI) et du Dashboard HTML pour requêter et afficher la nouvelle métrique de vitesse. | Maintenir la parité entre l'usine (OT) et la supervision (IT). |
| **CHG-V2-008** | 2026-04-18 | ⚙️ [OT - OPC UA] | Ajout d'une troisième cellule robotisée au simulateur. Enrichissement majeur du modèle de données : Type de robot, Progression du cycle, Alarmes actives, Temps avant maintenance. | Représenter un cas d'usage plus réaliste et complexe (3 types de robots différents). |
| **CHG-V2-009** | 2026-04-18 | 🌐 [IT - Web] | Implémentation d'un système d'authentification par Token JWT (Opérateur vs Maintenance). Création d'une page de login. | Contrôler l'accès aux données sensibles et personnaliser l'affichage. |
| **CHG-V2-010** | 2026-04-18 | 🌐 [IT - Web] | Création d'un workflow de maintenance conditionnel : l'Opérateur voit un bouton "Appeler la maintenance" quand une machine est usée, la Maintenance voit l'historique des appels. Refonte du dashboard avec barres de progression. | Séparer les responsabilités selon les rôles industriels standard. |
| **CHG-V2-011** | 2026-04-18 | 🌐 [IT - Web] | Amélioration visuelle (UI/UX) du Dashboard : Le type de robot est affiché dans un "badge" gris, la barre de progression passe au rouge lors d'une alarme, et les alarmes sont mises en évidence dans une boîte d'alerte dédiée. | Faciliter la lecture rapide par les opérateurs dans un environnement industriel (Management Visuel). |
| **CHG-V2-012** | 2026-04-18 | ⚙️ [OT - OPC UA] | Les variables OPC UA sont passées en `writable` et la génération d'alarmes aléatoires est désactivée. | Permettre au serveur Web d'injecter des données pour simuler des scénarios (POC) de manière contrôlée. |
| **CHG-V2-013** | 2026-04-18 | 🌐 [IT - Web] | Ajout d'un "Panneau de Simulation" avec boutons interactifs pour forcer des défauts, avancer le compteur de maintenance, acquitter les erreurs et réaliser les maintenances. | Fournir un outil de test pour la soutenance du projet sans avoir à modifier le code Python. |

| **CHG-V2-017** | 2026-04-18 | ⚙️ [OT - OPC UA] | Ajout de variables de diagnostic approfondi (`TemperatureAxes`, `NiveauVibration`) qui évoluent dynamiquement lorsque la machine est en production. | Fournir des données prédictives d'usure réservées aux équipes techniques. |
