# Change and Decision Journal (V2)

This document tracks all major architectural changes and technical decisions made for version 2 of the project (NF EN 9100 Compliance).

**Component Legend:**
- ⚙️ **[OT - OPC UA]**: Industrial data server (Factory simulator `opcua_server.py`)
- 🌐 **[IT - Web]**: Supervision server and dashboard (FastAPI `web_server.py`)
- 🛡️ **[Global]**: Architecture, cross-cutting security, certificates, or documentation
